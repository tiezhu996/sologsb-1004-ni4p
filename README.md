# 博物声 · 博物馆展陈脚本工作台

面向博物馆内容团队的展陈脚本编写、审校与版本管理工具。项目按“展厅 → 展项 → 语言”组织内容，覆盖标题、讲解词、无障碍描述、朗读时长和资料来源。

## 功能

- 展厅、展项切换，以及中文、英文、日文多语言稿件进度对照。
- 草稿、待审、退回、已定稿四态流转；已确认段落可锁定，避免误改。
- 分段校对、预计朗读时长、自动字数/语速估算和来源核验。
- 完整版本快照、句子级差异比较和版本恢复。
- **巡展交接包**：离线导出/回馆导入，按共同基线逐字段三方对账，只接收单边变化，双边同改列为冲突待裁决。
- 桌面、平板、手机、馆内触摸屏四种排版预览。
- 浏览器本地持久化，刷新后恢复；最多 50 步撤销重做。
- `Ctrl/⌘ + Z`、`Ctrl/⌘ + Shift + Z`、`Ctrl/⌘ + S` 快捷键与语义化表单标签。

## 巡展交接包

面向“无网展馆改稿、回馆整库导入”的协作场景，避免馆内刚锁定的段落被旧稿覆盖：

1. **导出**：交接包为每个展厅、展项和每种语言稿（含段落）携带一份**共同基线**快照，以及已删除段落的编号（墓碑）。
2. **离线改稿**：巡展组在展厅用导出的副本工作，馆内仍可继续编辑、锁定。
3. **回馆对账**：导入时对每个记录的每个字段比较「基线 / 馆内当前 / 巡展当前」三方：
   - 只有一边改过 → 自动接收；
   - 两边改成相同结果 → 静默一致；
   - 同一字段两边都改过且不同 → 列为**冲突**，界面并列双方内容，逐条选定“保留馆内/采用巡展”后才写入。
4. **段落增删**：按稳定编号识别。删除会记下墓碑，旧交接包无法把已删段落复活；巡展端删除而馆内改过该段时同样列为冲突。
5. **回执与幂等**：每个包有唯一编号，重复导入同一包只返回原有回执，绝不重复写入。
6. **事务安全**：裁决写入是整笔事务，任何一步失败都恢复到导入前状态；未决冲突现场持久化保留，刷新后可继续裁决。
7. **旧数据升级**：升级前保存的本地数据在首次打开时自动以当前全库补齐基线。

## 技术栈

- Nuxt 3、Vue 3、TypeScript、Pinia
- Vuetify 3
- 浏览器 `localStorage`

## 本地开发

```bash
npm install
npm run dev
```

开发服务器默认监听 `http://localhost:3000`。应用不包含宿主端口配置。

## 测试与检查

```bash
npm run typecheck   # 类型检查
npm test            # 巡展对账引擎与导入事务测试（无需浏览器）
```

## 生产构建

```bash
npm install
npm run build
```

静态产物位于 `.output/public`。可用 `npm run preview` 预览。

## Docker

```bash
docker build -t sologsb-1004 .
docker run --rm -p 10004:80 sologsb-1004
```

容器内 nginx 监听 80，静态单页回退到 `index.html`。根据根端口表，本地映射为宿主 `10004`。

## 数据说明

所有数据只保存在当前浏览器。清除站点数据会删除本地稿件；版本快照保存在同一份本地数据中。
